# links.nunddigo.com 배포 가이드

> 코드·설정은 전부 끝났습니다. 대표님이 하실 건 **딱 3가지**입니다.

---

## 대표님이 하실 일 3가지

### 1단계 · GitHub에 올리기 (2분)

터미널에서 `nunddigo-web` 폴더로 이동한 뒤 아래 세 줄을 그대로 붙여넣으세요.

```
git add .
git commit -m "links 사이트 추가 + links.nunddigo.com 라우팅"
git push
```

> 이것만 하면 Cloudflare가 **자동으로 새 버전을 배포**합니다. (eyetest·eyefit 때와 동일)

---

### 2단계 · Cloudflare에 도메인 연결 (3분)

1. [dash.cloudflare.com](https://dash.cloudflare.com) 접속
2. 왼쪽 메뉴 **Workers & Pages** → **nunddigo-web** 클릭
3. 상단 **Settings** 탭 → **Domains & Routes** 
4. **+ Add** → **Custom domain** 선택
5. 입력창에 `links.nunddigo.com` 입력 → **Add domain**
6. 끝. DNS는 Cloudflare가 알아서 만듭니다 (1~2분 대기)

> eyetest·eyefit을 붙일 때 했던 것과 **똑같은 절차**입니다.

---

### 3단계 · GA4 연결 (5분, 나중에 해도 됨)

1. [analytics.google.com](https://analytics.google.com) → 관리(톱니바퀴) → **속성 만들기**
2. 속성 이름 `눈띄고 링크` → 다음 → 업종·규모 대충 선택 → 만들기
3. 플랫폼 **웹** 선택 → 웹사이트 URL에 `links.nunddigo.com` 입력 → 스트림 만들기
4. 화면에 뜨는 **측정 ID** 복사 (`G-` 로 시작하는 것)
5. `links/index.html` 파일을 열어 **맨 아래**를 찾으세요:

```html
<!-- GA4 · 측정 ID 발급 후 G-XXXXXXXXXX 교체하고 주석 해제
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>window.dataLayer=window.dataLayer||[];function gtag(){dataLayer.push(arguments);}gtag('js',new Date());gtag('config','G-XXXXXXXXXX');</script>
-->
```

6. 맨 앞의 `<!--` 와 맨 뒤의 `-->` **두 개만 지우세요**
7. `G-XXXXXXXXXX` 세 군데를 복사한 측정 ID로 바꾸세요
8. 1단계의 git 세 줄을 다시 실행

> 이걸 해야 **어떤 링크가 상담으로 이어지는지** 알 수 있습니다. 페이지뷰만 보면 의미가 없습니다.

## 확인 방법

배포 후 브라우저에서 `https://links.nunddigo.com` 접속.

| 확인 항목 | 정상 |
|---|---|
| 심볼 깜빡임 | 2~3초 뒤 작은 눈이 한 번 감았다 뜸 |
| 상단바 | 스크롤하면 위에서 내려옴 |
| 진행바 | 스크롤할수록 초록선이 차오름 |
| 썸네일 | 마우스 올리면 흑백 → 컬러 |
| 하단바 | 마우스 올리면 카피가 바뀜 |
| 공유 버튼 | 눌러서 공유창 또는 "주소를 복사했습니다" |

## 이미 세팅된 것 (대표님이 안 하셔도 됨)

- 워커 라우팅 `links.nunddigo.com` → `/links` (`src/index.js`)
- `/links` → `/links/` 리다이렉트 (`_redirects`)
- 캐시 정책: HTML 즉시 갱신 / 로고 1년 / 이미지 7일 (`_headers`)
- 보안 헤더 (X-Frame-Options, nosniff, Referrer-Policy)
- `robots.txt` · `sitemap.xml` (검색 허용)
- Organization 스키마 + sameAs (AI·검색 인용용)
- OG·트위터 카드 메타
