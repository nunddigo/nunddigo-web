## 배포하는 법 (가장 쉬운 방법)

`nunddigo-web` 폴더 안의 **`배포.command`** 파일을 **더블클릭**하세요.

1. 바뀐 파일 목록이 뜹니다
2. 메모를 적거나 그냥 엔터
3. 끝. 1~2분 뒤 사이트 반영

> 처음 한 번만: 파일 우클릭 → 열기 → "열기" 한 번 눌러주면 이후로는 더블클릭만으로 됩니다.

**터미널이 편하시면**
```
git add . && git commit -m "update" && git push
```

## 다음에 할 것 (급한 순서)

### 1순위 · 스레드 프로필·고정글 링크 교체 ★
지금 스레드 프로필에 걸린 리틀리 주소를 `links.nunddigo.com`으로 바꾸세요.
**이걸 안 하면 사이트를 만든 의미가 없습니다.** 두 도구는 검색에 안 잡히니(noindex) 유입 경로가 여기뿐입니다.

### 2순위 · 리틀리 정리
리틀리 페이지 맨 위에 한 줄 추가: `새 주소로 옮겼습니다 → links.nunddigo.com`
명함·이전 글에 박힌 링크가 있으니 **3개월 뒤에 삭제**하세요.

### 3순위 · 서치콘솔 등록 (10분)
1. [search.google.com/search-console](https://search.google.com/search-console) → 속성 추가
2. **URL 접두어** 선택 → `https://links.nunddigo.com` 입력
3. 소유권 확인 → **HTML 태그** 방식 선택 → 나오는 `<meta>` 한 줄 복사
4. `links/index.html` 의 `<head>` 안 아무 데나 붙여넣기 → 배포
5. 확인 완료되면 좌측 **Sitemaps** → `sitemap.xml` 입력 → 제출

> 네이버는 [searchadvisor.naver.com](https://searchadvisor.naver.com) 에서 같은 절차.

### 4순위 · 한 달 뒤 숫자 보기
GA4 → 보고서 → 참여도 → 이벤트

| 볼 것 | 의미 |
|---|---|
| `click_eyetest` vs `click_eyetest_final` | 위에서 바로 누르나, 끝까지 읽고 누르나 |
| `click_eyetest` 대비 `click_kakao` | 도구가 일하나, 콘텐츠가 일하나 |
| `click_share` | 남에게 보여줄 만한 페이지인가 |

## 파일 어디에 뭐가 있나

```
nunddigo-web/
├── 배포.command          ← 더블클릭하면 배포
├── src/index.js          ← 서브도메인 라우팅 (links/eyetest/eyefit)
├── _headers              ← 보안·캐시 설정
├── _redirects            ← 주소 리다이렉트
├── 404.html              ← 없는 페이지
└── links/
    ├── index.html        ← 링크 사이트 본체
    ├── logos/            ← 로고월 25개
    └── thumb_*.jpg       ← 썸네일
```

**자주 바꿀 것**
- 링크 추가·삭제 → `links/index.html` 에서 해당 섹션
- 후기 추가 → `06 · 받은 말들` 섹션
- 로고 추가 → `logos/` 에 파일 넣고 `index.html` 맨 아래 JS 배열에 파일명 추가

## 주의사항

- **로고월**: 흰 배경 로고나 어두운 배경 로고는 안 보입니다. 넣기 전 흰 카드 위에서 확인하세요
- **후기**: 실제 받은 것만. 창작 금지
- **이미지**: 새 이미지는 넣기 전 용량 확인. 200KB 넘으면 줄이세요
- **월 1회**: 링크 전부 눌러보고 죽은 링크 없는지 확인 (404는 신뢰를 즉사시킵니다)
