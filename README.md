# 눈띄고 웹 (nunddigo-web)

눈띄고 자사 사이트. STEP2 "웹을 세운다"의 1호 실적 — 눈띄고가 눈띄고에게 지은 첫 웹.

## 구조
- `/` — 홈 (브랜드 정체성 + AEO Organization 스키마)
- `/eyetest/` — 브랜드 시력검사 도구 (noindex, 링크 공유 전용)

## 스택
정적 HTML/CSS/JS, 빌드 없음. GitHub → Netlify 연결 배포(push하면 자동 배포).

## 아직 미정 (다음 커밋에서 반영)
- STEP1/2/3 가격 — 대표 확정 대기 (`눈띄고_세계관_마스터_확정본_v1.md` PART D)
- 홈 전용 OG 이미지 — 현재는 시력검사 도구 OG 이미지 재사용 중
- `/ideas` 블로그 뼈대 — 검색어전략 문서의 6편 클러스터용
- 커스텀 도메인 연결

## 규율
- 내부 격리 용어(검안·도수·조제·피팅·란돌트·듀오크롬) 대외 카피 사용 금지
- 없는 숫자·실적 창작 금지 (정직 원칙)
